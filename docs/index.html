      Exportar a SPSS

      1. Descarga la base (CSV con valores codificados, una fila por paciente).
      2. Descarga la sintaxis el mismo día (contiene el nombre del CSV, las etiquetas de variables y de valores y el nivel de medición).
      3. Guarda ambos archivos en una carpeta, por ejemplo C:\SPSS\Protocolo_EVC.
      4. En SPSS 27: Archivo → Abrir → Sintaxis… → elige el .sps, escribe la ruta de tu carpeta en la línea CD y usa Ejecutar → Todo. Se crea base_evc.sav listo para el análisis.

      Ayuda

      Flujo de trabajo

      1. Nuevo registro: el folio se propone automáticamente (EVC-001, EVC-002…). Verifica los criterios de selección: el dictamen se calcula solo.
      2. Captura las secciones II a VI desde el expediente clínico electrónico. El NLR, su categoría, la categoría NIHSS, el tiempo síntomas-puerta y la ventana de seguimiento se calculan automáticamente.
      3. Puedes guardar con datos incompletos y volver después. La lista de registros indica cuándo abre la ventana de 90 ± 14 días de cada paciente.
      4. Seguimiento a 90 días: abre el registro, captura la fuente de información, la mRS (usa el asistente de entrevista telefónica del Anexo 6 si aplica) y la mortalidad.

      Usar en el celular (iPhone y Android)

      1. Abre https://davmz86.github.io/protocolo-ictus-inl/ en Safari (iPhone) o Chrome (Android). Si llegó por WhatsApp, Facebook u otra app, usa «Abrir en el navegador»: dentro de esas apps Google puede bloquear el inicio de sesión.
      2. Toca Acceder con Google y elige tu cuenta. Si no aparece la ventana de Google, permite las ventanas emergentes para este sitio.
      3. Para tenerla como app: iPhone → botón Compartir → «Agregar a pantalla de inicio»; Android → menú ⋮ → «Agregar a la pantalla principal».
      4. Si ves «Modo demostración», toca «Salir e iniciar sesión con Google» o abre la dirección sin ?demo al final.

      Confidencialidad

      El nombre, el NSS y el teléfono del paciente (marcados 🔒) sirven sólo para localizar el expediente y hacer el seguimiento. Se guardan aparte, en la hoja «Identificacion», y nunca se incluyen en la exportación a SPSS ni en la lista de registros. No los escribas en otros campos (por ejemplo, en observaciones). Los archivos adjuntos pueden contener datos personales: súbelos sólo cuando sean necesarios para el protocolo.
